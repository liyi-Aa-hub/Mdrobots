# Mdrobots
你有没有过这种时候——下班前被老板一句话整破防，或者连开四小时会电量归零，又或者周五终于解放却不知道该吃点什么犒劳自己？ 这时候你需要的不是营养学建议，而是一个懂你情绪、还懂麦当劳菜单的搭子。
# 🍔 麦当劳情绪盲盒 (McDonald's Mood BlindBox)
本项目为 1024 切磋大会【用餐】赛道参赛作品。

## 💡 创意来源
打工人的午餐不仅仅是为了填饱肚子，更是情绪的宣泄口。本项目利用 WorkBuddy 平台结合麦当劳 MCP，根据用户输入的“心情”和“预算”，自动搭配出能治愈情绪、补充能量的“情绪盲盒套餐”。

## 🛠️ 技术实现
- 开发平台：WorkBuddy
- 核心能力：麦当劳 MCP（实时查询菜单与价格）
- 配置文件：见本仓库 `workbuddy.md`

## 🎮 如何体验
1. 访问 WorkBuddy 平台发布的链接（此处填入你在 WorkBuddy 发布后生成的体验链接）。
2. 输入你的心情（如：“今天被老板骂了，很emo，预算30元”）。
3. 稍等片刻，即可获得你的专属情绪盲盒套餐。
